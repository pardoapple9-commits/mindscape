#  Mindscape

## Descripción

Mindscape es un proyecto educativo e interactivo que busca acercar a los estudiantes al mundo de la Psicología mediante el uso de tecnología y experiencias digitales.

## Objetivo

El objetivo de Mindscape es presentar la Psicología de una manera innovadora, atractiva y fácil de comprender para los estudiantes.
